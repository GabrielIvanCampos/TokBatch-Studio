Ajuda

Como baixar os vídeos de um perfil.

Cole o link de um perfil do TikTok e clique em “Baixar vídeos”. O programa baixa os vídeos disponíveis para a pasta selecionada.

Perfis públicos funcionam sem cookies. Se o perfil for privado e você tiver acesso, escolha o navegador em que já está conectado.

Use somente conteúdo seu ou que você tenha permissão para salvar.
